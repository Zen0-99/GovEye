### Task 4: Add `observeInterestsForMemberInRange()` to `InterestDao`
**File:** `core/data/src/main/java/com/goveye/app/data/local/dao/InterestDao.kt`
**Action:** edit
**Description:**

Add a new query method for the date filter feature (R4). The query filters interests by `publishedDate` inclusive on both ends (`from ≤ publishedDate ≤ to`), ordered by `publishedDate DESC` (same ordering as the existing `observeInterestsForMember`). Both `fromDate` and `toDate` are ISO date strings (e.g. `"2024-01-01"`), matching the `publishedDate` column format. When either parameter is null, that bound is ignored (open-ended range).

**Changes to make:**

Add after the existing `observeInterestsForMember` query (line 12):

```kotlin
@Query("""
    SELECT * FROM interests
    WHERE memberId = :memberId
      AND (:fromDate IS NULL OR publishedDate >= :fromDate)
      AND (:toDate IS NULL OR publishedDate <= :toDate)
    ORDER BY publishedDate DESC
""")
fun observeInterestsForMemberInRange(
    memberId: Int,
    fromDate: String?,
    toDate: String?,
): Flow<List<InterestEntity>>
```

The `IS NULL` check on the bound parameters allows Room to short-circuit the comparison when a bound is not provided (SQLite evaluates `NULL IS NULL` as true). This avoids needing separate queries for open-ended ranges.

**Acceptance:**
- `observeInterestsForMemberInRange(memberId, fromDate, toDate)` returns `Flow<List<InterestEntity>>`
- With `fromDate = "2024-01-01"`, `toDate = "2024-12-31"`: returns only interests with `publishedDate` in 2024
- With `fromDate = null`, `toDate = null`: returns all interests (same as `observeInterestsForMember`)
- With `fromDate = "2099-01-01"`, `toDate = null`: returns empty (no future-dated interests)
- Results ordered by `publishedDate DESC`
- Compiles without errors

### Task 5: Rewrite `InterestsRepository` — DAO only, no API, no mapper, no staleness
**File:** `core/data/src/main/java/com/goveye/app/data/repo/InterestsRepository.kt`
**Action:** edit (full rewrite)
**Description:**

Rewrite the repository to match the pattern established by `VotesRepository` and `CommitteesRepository` (R5): inject only `InterestDao`, no `InterestsApi`, no `InterestMapper`, no `refresh()` method, no `CacheTtl` staleness check. `SyncStatus` is `FRESH` if data exists, `EMPTY` if not. Add `observeInterestsForMemberInRange()` for the date filter.

The `toDomain()` extension function is updated to map the 3 new columns from `InterestEntity` to the `Interest` domain model.

**Full replacement content:**

```kotlin
package com.goveye.app.data.repo

import com.goveye.app.data.local.dao.InterestDao
import com.goveye.app.data.local.entity.InterestEntity
import com.goveye.app.domain.model.Interest
import com.goveye.app.domain.model.RepositoryResult
import com.goveye.app.domain.model.SyncStatus
import javax.inject.Inject
import javax.inject.Singleton
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.map

@Singleton
class InterestsRepository @Inject constructor(
    private val interestDao: InterestDao,
) {
    fun observeInterestsForMember(memberId: Int): Flow<RepositoryResult<List<Interest>>> =
        interestDao.observeInterestsForMember(memberId).map { entities ->
            if (entities.isEmpty()) {
                RepositoryResult(emptyList(), SyncStatus.EMPTY)
            } else {
                RepositoryResult(entities.map { it.toDomain() }, SyncStatus.FRESH)
            }
        }

    fun observeInterestsForMemberInRange(
        memberId: Int,
        fromDate: String?,
        toDate: String?,
    ): Flow<RepositoryResult<List<Interest>>> =
        interestDao.observeInterestsForMemberInRange(memberId, fromDate, toDate).map { entities ->
            if (entities.isEmpty()) {
                RepositoryResult(emptyList(), SyncStatus.EMPTY)
            } else {
                RepositoryResult(entities.map { it.toDomain() }, SyncStatus.FRESH)
            }
        }

    private fun InterestEntity.toDomain(): Interest =
        Interest(
            id = id,
            memberId = memberId,
            summary = summary,
            categoryName = categoryName,
            categoryNumber = categoryNumber,
            registrationDate = registrationDate,
            publishedDate = publishedDate,
            fieldsJson = fieldsJson,
            parsedAmountPence = parsedAmountPence,
            currencyCode = currencyCode,
            bucket = bucket,
        )
}
```

- `import com.goveye.app.data.mapper.InterestMapper` — removed
- `import com.goveye.app.data.local.entity.InterestEntity` — kept (used in `toDomain`)
- `interestsApi: InterestsApi` constructor parameter — removed
- `mapper: InterestMapper` constructor parameter — removed

- `CacheTtl.INTERESTS_MS` staleness check — removed
- `System.currentTimeMillis()` reference — removed
- `interestDao.upsertAll(entities)` call — removed (patches handle upserts now)

**Acceptance:**
