```python
# Maps API category number (string) to high-level bucket label.

BUCKET_MAPPING = {

def get_bucket(category_number: str) -> str | None:
    """Map an API category number to a high-level bucket label.
    Falls back to the parent category (e.g. '1.1' → '1' → 'Employment/Earnings').
    Returns None if no mapping found.

    if category_number in BUCKET_MAPPING:
```

**`parse_amount(fields_json: str) -> tuple[int | None, str | None]` function (D-01, D-02, D-03):**

Two-tier monetary parser. Deserializes `fields_json` (a JSON string of `List<InterestFieldDto>`) and extracts a monetary amount.

**Tier 1 — Structured fields:**
- Parse `fields_json` with `json.loads()`.
- Iterate over the fields list. For each field:
  - Check `field.get("typeInfo", {}).get("currencyCode")` — if present, this field has structured currency info.
  - Check `field.get("value")` — if it's a number (int/float), convert to pence (round to nearest int) and return `(pence, currency_code)`.
  - If `value` is a string, pass it to Tier 2 regex.
  - Check `field.get("name")` — if it contains "Amount", "Value", "Rate", "Payment" (case-insensitive), treat the field as a candidate for monetary extraction.

**Tier 2 — Regex on free text:**
Core pattern (based on mySociety's proven approach, D-02):
```python
import re

# Core: £ followed by number with optional thousands separators
POUND_PATTERN = re.compile(
    r'£\s?(\d{1,3}(?:,\d{3})*(?:\.\d+)?)\s*'
    r'(million|billion|thousand|m|bn|k)?',
    re.IGNORECASE,
)

# Range: £X to £Y, £X–£Y, £X-£Y → take the higher value
RANGE_PATTERN = re.compile(
    r'£\s?(\d{1,3}(?:,\d{3})*(?:\.\d+)?)\s*(?:to|[-–])\s*'
    r'£?\s?(\d{1,3}(?:,\d{3})*(?:\.\d+)?)',
    re.IGNORECASE,
)
```

Logic:
1. Try `RANGE_PATTERN` first — if matched, take the higher of the two values (conservative, per RESEARCH.md edge case).
2. Try `POUND_PATTERN` — if matched, extract the number.
3. Apply multiplier: `million`/`m` → ×1,000,000, `billion`/`bn` → ×1,000,000,000, `thousand`/`k` → ×1,000.
4. Convert to pence: `int(round(amount * 100))`.
5. If no match, return `(None, None)`.

**Edge cases (from SPEC.md + RESEARCH.md):**
- `£0` → `(0, "GBP")` (valid zero)
- Negative amounts (`-£X`) → handle gracefully: if the text has a minus before £, negate the pence.
- Large amounts (`£1.5 million`) → `150000000` pence
- Ranges (`£5,000 to £10,000`) → `1000000` pence (higher value)
- Hourly rates (`£50/hour`) → `5000` pence (store the hourly rate, not annualized)
- No money mentioned → `(None, None)` (never fabricate)
- If `typeInfo.currencyCode` is present, use it as the currency code. Otherwise default to `"GBP"` if a £ amount was found, `None` otherwise.

**`map_interest_to_entity(interest_dto, timestamp_millis)` function:**

Map an `InterestDto` to an `interests` table row tuple. Follows the field mapping from `InterestMapper.kt` (which is being deleted in 09-02 — the mapping logic moves here).

```python
def map_interest_to_entity(interest_dto, timestamp_millis):
    category = interest_dto.get("category") or {}
    category_number = category.get("number") or ""
    fields_json = json.dumps(interest_dto.get("fields") or [])
    parsed_pence, currency_code = parse_amount(fields_json)
    bucket = get_bucket(category_number)

    return (
        interest_dto.get("id") or 0,           # id
        (interest_dto.get("member") or {}).get("id", 0) or 0,  # memberId
        interest_dto.get("summary") or "",      # summary
        category.get("id") or 0,                # categoryId
        category_number,                         # categoryNumber
        category.get("name") or "",             # categoryName
        interest_dto.get("registrationDate"),    # registrationDate
        interest_dto.get("publishedDate"),       # publishedDate
        1 if interest_dto.get("rectified", False) else 0,  # rectified
        fields_json,                             # fieldsJson
        timestamp_millis,                        # lastUpdated
        parsed_pence,                            # parsedAmountPence
        currency_code,                           # currencyCode
        bucket,                                  # bucket
    )
```
