1. Add `MIGRATION_23_24` following the idempotent `ALTER TABLE` pattern (same as `MIGRATION_18_19`):

```kotlin
// Migration 23 → 24: Add 16 structured interest fields (Phase 18).
// Idempotent — the seed DB may already include these columns if built
// with a newer bundled_schema.json.
private val MIGRATION_23_24 = object : Migration(23, 24) {
    override fun migrate(db: SupportSQLiteDatabase) {
        val existingColumns = db.query("PRAGMA table_info(interests)").use { cursor ->
            buildList {
                while (cursor.moveToNext()) {
                    add(cursor.getString(cursor.getColumnIndexOrThrow("name")))
                }
            }
        }.toSet()

        val newColumns = listOf(
            "donorName",
            "paymentType",
            "paymentDescription",
            "donorStatus",
            "donorAddress",
            "donorCompanyIdentifier",
            "destination",
            "visitPurpose",
            "organisationName",
            "organisationDescription",
            "propertyLocation",
            "propertyType",
            "hoursWorked",
            "familyMemberName",
            "familyMemberRelationship",
            "familyMemberRole"
        )

        for (colName in newColumns) {
            if (colName !in existingColumns) {
                db.execSQL("ALTER TABLE interests ADD COLUMN `$colName` TEXT")
            }
        }
    }
}
```

2. Add `MIGRATION_23_24` to the `addMigrations(...)` call in `provideBundledDatabase()` (after `MIGRATION_22_23`).

**Acceptance criteria:**
- `MIGRATION_23_24` is defined with `Migration(23, 24)`.
- All 16 columns are added as `TEXT` (nullable).
- Migration is idempotent — checks `PRAGMA table_info(interests)` before each `ALTER TABLE`.
